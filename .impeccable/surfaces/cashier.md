# Cashier surface

Mode: Operate.

Routes: WordPress front controller `?upos_app=1` and protected receipt route. Primary success is a WooCommerce order paid once, with a readable printable receipt. All product and payment data are real server data.

First viewport: compact store/operator header, search that accepts name/SKU, live product grid, clear stock labels, and a persistent basket showing a visibly provisional estimate until the server prepares the sale. Empty cart explains how to add the first item. Payment confirmation is not visible until the server has returned the actual order total.

The catalog/order split, structural desktop/mobile changes, focused search shortcut and precise financial states are the intended craft. No hero, marketing claims, metrics or decorative motion. Inspect desktop and mobile together once, correct defects as a batch, and make at most one confirmation pass.
