# گزارش آزمون نسخهٔ 0.3.0 — رابط صندوق و فاکتور

تاریخ: ۲۰۲۶-۱۱-۰۵. این نسخه ادامهٔ **مرحلهٔ ۲** در ترتیب توسعهٔ کاربر است؛ شمارهٔ نسخه، شمارهٔ مرحلهٔ کاری نیست.

محیط واقعی: PHP 8.4.24، WordPress 6.8.3، WooCommerce 9.9.5، MariaDB 11.8.6، Chromium 155 و Playwright. داده‌های مرورگر از کالاها و کاربران موقت واقعی در دیتابیس WooCommerce ساخته شدند؛ API یا نتیجهٔ پرداخت موفق جعل نشد.

## نتیجه

**۲۳۵ بررسی موفق:**

| مجموعه | تعداد | نتیجه |
| --- | ---: | --- |
| هسته، دیتابیس، API خواندن و nonce | ۳۴ | موفق |
| فروش و پرداخت در دو حالت HPOS | ۱۱۷ | موفق |
| همزمانی با فرایندهای مستقل | ۱۲ | موفق |
| نبود WooCommerce | ۱ | موفق |
| رابط، مجوزها، زبان و API بازیابی | ۲۰ | موفق |
| مرورگر واقعی، صندوق/فاکتور/قطع پاسخ | ۴۶ | موفق |
| رابط انگلیسی در دسکتاپ و موبایل | ۵ | موفق |

تمام فایل‌های PHP و syntax فایل‌های JavaScript بررسی شدند. در اجرای نهایی debug.log جدیدی برای خطا یا هشدار PHP ایجاد نشد. خطاهای عمدی rollback در آزمون‌های سرور، بخشی از سناریوی مورد انتظار هستند و با پاسخ صحیح بررسی شدند.

## شواهد جدید این نسخه

- ورود به صفحهٔ مستقل صندوق فقط با نشست WordPress و قابلیت‌های فروش/موجودی؛ کاربر ناشناس به ورود هدایت و subscriber رد شد.
- درخواست HTTP واقعی با nonce نامعتبر، ۴۰۳ گرفت. نشست‌های آزمایشی با سازوکار استاندارد WordPress امضا شده بودند.
- کاتالوگ واقعی، جست‌وجوی دقیق SKU محصول و variation، انتخاب و تغییر تعداد با کیبورد، و نمایش سبد در دو عرض ۱۴۴۰ و ۳۹۰ پیکسل.
- رابط فارسی راست‌به‌چپ بدون وابستگی به بستهٔ زبان WordPress و رابط انگلیسی چپ‌به‌راست؛ نبود overflow افقی در هر دو زبان و هر دو عرض.
- ثبت مشتری مهمان، آماده‌سازی سفارش واقعی، قفل‌شدن سبد پس از رزرو، تأیید صریح دریافت وجه و پرداخت ترکیبی واقعی با دو ردیف دفتر مالی.
- تأیید کاهش موجودی کالای ساده و موجودی مشترک والد variation پس از ثبت در مرورگر؛ بازخوانی نتیجه، دریافت یا سفارش تکراری ایجاد نکرد.
- قطع عمدی تحویل پاسخ آماده‌سازی **پس از commit واقعی سرور**؛ بازیابی همان سفارش از کلید درخواست.
- قطع عمدی تحویل پاسخ پرداخت **پس از commit واقعی سرور**؛ بازیابی یک دریافت ثبت‌شده، بدون دریافت دوباره یا پرداخت اضافی.
- قطع درخواست پیش از رسیدن به سرور، انصراف پایدار، و رد POST دیررس با همان کلید؛ سفارش ناخواسته ساخته نشد.
- چاپ فاکتور از سفارش واقعی با مشتری، تاریخ، اقلام، مبلغ، روش‌ها و شمارهٔ پیگیری؛ عرض‌های محتوای ۵۴ و ۷۶ میلی‌متر برای کاغذ ۵۸/۸۰.
- تولید PDF آزمایشی با دو عرض فیزیکی، حذف کنترل‌های چاپ از خروجی و بررسی متفاوت‌بودن عرض دو قالب.
- عدم صدور فاکتور پرداخت‌شده برای سفارش pending؛ صندوق‌دار دیگر برای فاکتور همان سفارش پاسخ ۴۰۴ گرفت.
- لغو فروش پرداخت‌نشده، نمایش آفلاین بدون صف فروش، بازیابی فهرست فروش‌های همان صندوق‌دار و نبود ذخیرهٔ سبد/مشتری/پرداخت در localStorage یا sessionStorage.
- خطای محدودیت موجودی در تب فعال کاتالوگ موبایل دیده شد؛ قیمت و موجودی با `aria-describedby` به هر محصول متصل شدند؛ لمس محصول فوکوس را به جست‌وجو و کیبورد منتقل نکرد.
- تنظیم زبان، بازیابی کلید و فهرست اخیر به کاربر محدودند؛ attempt لغوشدهٔ بدون سفارش از فهرست فروش‌ها حذف می‌ماند.

## بازبینی بصری

تصاویر دسکتاپ، موبایل و دو قالب چاپ در یک بازبینی مستقل خوانده شدند. دو اصلاح مادی بازبین، یعنی پیام خطای پنهان در موبایل و توضیح ناکافی قیمت/موجودی برای صفحه‌خوان، همراه با اصلاح فوکوس لمس در یک دسته انجام شدند و آزمون مرورگر برای آن‌ها اضافه شد. بازبین در گذر نهایی با نتیجهٔ **ship** هر سه اصلاح را در محدودهٔ همان یافته‌ها تأیید کرد؛ این نتیجه، ممیزی تازهٔ کل برنامه یا گواهی کامل دسترس‌پذیری نیست.

ابزار context و detector مهارت Impeccable در این محیط نصب نبودند؛ تلاش اجرا با کد ۱۲۷ برگشت. طراحی و بازبینی از مشخصات موجود، سورس و تصاویر واقعی انجام شد و هیچ خروجی detector فرض نشده است.

## محدودیت اعتبار

آزمون‌های سرور HPOS روشن/خاموش را پوشش می‌دهند؛ آزمون HTTP مرورگر با تنظیم ذخیره‌سازی فعلی سایت موقت اجرا شد. HPOS با sync فعال، Redis/object cache خارجی، نسخه‌های دیگر مرورگر، چندسایتی، افزونه‌های ثالث و MySQL مستقل از MariaDB در این اجرا بررسی نشدند.

PDF و رسانهٔ چاپ در Chromium آزمایش شدند، نه چاپگر فیزیکی، درایور سخت‌افزاری یا اتصال کارت‌خوان. تحویل SMTP در محیط موقت با فیلتر استاندارد متوقف شد. آزمون مرحله‌ای جای مجموعهٔ آزمون نهایی همهٔ ماژول‌های پروژه را نمی‌گیرد.

داده‌ها و نشست‌های موقت مرورگر پس از آزمون پاک و تنظیمات سایت آزمایشی به حالت قبلی بازگردانده شدند. تصاویر و PDFها خارج از ZIP محصول‌اند. گزارش‌های تاریخی [0.2.0](test-report-0.2.0.md) و [0.1.0](test-report-0.1.0.md) حفظ شده‌اند.
