# گزارش آزمون مرحلهٔ اول

تاریخ: ۲۰۲۶-۱۱-۰۵ — نسخهٔ افزونه: 0.1.0

## محیط واقعی اجرا

- PHP 8.4.24
- WordPress 6.8.3
- WooCommerce 9.9.5، بستهٔ رسمی انتشار
- MariaDB 11.8.6 با دیتابیس موقت و پیشوند `test_`
- افزونهٔ نصب‌شده از ZIP استخراج‌شده، بدون دادهٔ نمایشی در کد محصول

PHP و MariaDB به‌صورت محلی در `/workspace/tooling` آماده شدند. این فایل‌ها و دیتابیس آزمایشی بخشی از ZIP افزونه نیستند. آزمون‌ها از CLI و REST dispatcher واقعی WordPress استفاده می‌کنند؛ مرورگر یا احراز هویت Application Password روی HTTP در این مرحله آزمایش نشده است.

## نتیجهٔ نهایی

**۳۳ بررسی یکپارچه موفق + یک آزمون مستقل وابستگی موفق.**

- ایجاد هر پنج جدول با پیشوند پویا، درج مقدار مالی اعشاری و رد کلید پرداخت تکراری در دیتابیس واقعی.
- اجرای مجدد مهاجرت بدون حذف داده و ثبت نسخهٔ دیتابیس.
- خواندن فایل ترجمهٔ فارسی توسط ابزار استاندارد WordPress.
- رد nonce نامعتبر و پذیرش nonce معتبر توسط احراز هویت کوکی WordPress.
- رد کاربر ناشناس، محدودیت نقش صندوق‌دار و محدودیت اندازهٔ صفحه.
- مشاهدهٔ محصول WooCommerce و نمایش فوری تغییر قیمت و موجودی آن در API افزونه.
- جست‌وجوی SKU، شمارش نتایج، دریافت تنوع و ویژگی سایز.
- مقدار پیش‌فرض کانال `online`، نگهداری کانال `pos` و شناسهٔ صندوق‌دار پس از ذخیره و بارگذاری مجدد سفارش.
- اجرای همین بررسی‌های سفارش با HPOS خاموش و روشن، همراه با تأیید کلاس واقعی data store در هر حالت.
- پاسخ ۴۰۴ برای محصول ناموجود و غیرفعال‌کردن کش پاسخ‌ها.
- اجرای امن افزونه هنگام حذف WooCommerce فقط از فهرست افزونه‌های فعال همان فرایند آزمون؛ نمایش پیام وابستگی و ثبت‌نشدن API عملیاتی. تنظیم دائمی افزونه‌های سایت تغییر نکرد.
- بررسی syntax تمام ۱۴ فایل PHP، سلامت ZIP و `git diff --check` موفق بود.

در اجرای نهایی فایل debug جدیدی برای هشدار یا خطای PHP ایجاد نشد. داده‌های موقت محصول، سفارش، کاربر و پرداخت در پایان آزمون پاک شدند و تنظیمات HPOS به حالت اولیه برگشتند.

## بررسی‌های انجام‌نشده

این گزارش ادعای موفقیت ثبت فروش، پرداخت نقدی/ترکیبی، رزرو موجودی، کنترل فروش همزمان، کاهش موجودی توسط POS، مرجوعی، CRM، گزارش مالی یا رابط کاربری را ندارد؛ این ماژول‌ها هنوز ساخته نشده‌اند. کلید یکتای دیتابیس فقط تکرار درج همان کلید را متوقف می‌کند و جایگزین گردش اتمیک ثبت فروش نیست.

نسخه‌های حداقلی اعلام‌شدهٔ PHP 8.1، WordPress 6.7 و WooCommerce 9.0، ترکیب‌های دیگر نسخه‌ها و سایت چندگانهٔ واقعی در این اجرا بررسی نشده‌اند. فعال‌سازی شبکه‌ای عمداً رد می‌شود.

برای تکرار، دستورات و پیش‌نیازهای دیتابیس موقت در README آمده‌اند. این آزمون‌ها روی سایت اصلی اجرا نشوند.
